第一章 债权概述 第一节 债的概念与特征 债是按照合同的约定或者依照法律的规定，在当事人之间产生的特定的权利和义务关系。 特征： 1. 主体特定性 — 债权人和债务人都是特定的 2. 客体特定性 — 给付标的具有特定性 3. 请求性 — 债权人有权请求债务人履行义务 4. 财产性 — 债通常与财产利益相关

第二节 债的发生原因 一、合同 合同是债最主要的发生原因，是当事人之间设立、变更、终止民事法律关系的协议。 二、侵权行为 侵权行为是指行为人因过错侵害他人民事权益，应当承担侵权责任的行为。 三、无因管理 无因管理是指没有法定或约定义务，为避免他人利益遭受损失而为其管理事务的事实行为。 四、不当得利 不当得利是指没有合法根据取得利益而使他人遭受损失的事实。
