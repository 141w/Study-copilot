## 二、人工目视验收清单（建议过一遍）

启动方式：
```bash
cd backend && .venv/bin/python -m uvicorn app.main:app --port 8000
cd frontend && npm run dev   # http://localhost:3000
```

### A. 修复行为类（按改动风险排序）

- [ ] **AI 问答全流程**（ChatView 大改 + DocumentPicker 新组件）
  - 选文档（标签多选样式）→ 发问题 → 流式输出正常 → 来源徽章 `[N]` 点击展开来源卡
  - 「复制」按钮点后显示"已复制"2 秒后恢复；「朗读」可播放
  - 历史侧栏：重命名（点铅笔）、删除（点删除 → 确认弹窗）
  - 中文输入法选词中按回车**不应**发送（isComposing 处理）
- [ ] **做题练习**（P0-7 选项字母制——判分语义变更，务必真做一题）
  - 生成题目 → 选择选项 → 提交 → 判分正确性符合预期（选对的题应判对）
  - 考试模式「交卷」→ 结果汇总正确；错题本加载、「重做此题」可用
- [ ] **登录跳转链路**（P0-3）
  - 未登录直接访问 `/chat` → 跳登录页 → 登录成功后应回到 `/chat`（而非首页）
- [ ] **笔记系统**（useNoteDraft 重构 + NoteCard 归一化）
  - 新建笔记 → 输入 → 1 秒后刷新页面 → 草稿恢复
  - 编辑已有笔记 → 取消 → 再进编辑 → 内容是原笔记（草稿未污染）
  - 标签筛选、课程筛选、搜索可用；删除有确认弹窗
- [ ] **文档删除确认**（UploadView，原为无确认直接删）
- [ ] **模型配置**（el-form 校验 + toast）
  - 留空模型名保存 → 表单报错而非 alert；正常保存 → toast「配置保存成功」
  - 已保存 Key 显示掩码「已保存：sk-***…」
- [ ] **侧栏联动**（P3-2）
  - 文档阅读页选文档 → 侧栏"我的文档"对应项高亮；侧栏点文档 → 阅读页同步

### B. 样式精修类（切亮/暗双主题各看一遍）

- [ ] **品牌渐变统一**：logo、AI 头像、聊天空态图标、学习分析进度条均为蓝→紫渐变（不再是洋红→橙）
- [ ] **Hero 区**：首页顶部为极淡品牌微光（不再是粉彩横幅）；中文标题无挤压感
- [ ] **暗色模式层次**：卡片与背景可区分（不再同色糊成一片）；阴影不发脏
- [ ] **弹窗圆角**：el-dialog 圆角与卡片同级（不再比卡片更方）
- [ ] **滚动条**：暗色下聊天记录/文档内容区滚动条为深灰细条（非浏览器默认白条）
- [ ] **文本选中色**：选中任意文字为淡蓝色（品牌色系）
- [ ] **侧栏 active**：当前导航项有淡蓝胶囊背景 + 加粗（非仅文字变色）
- [ ] **空状态**：圆形图标带边框、主文案较清晰
- [ ] **学习分析**：三个统计大数字用等宽数字（变化时不跳动）
- [ ] **触屏/键盘**：Tab 键走查有可见焦点环；移动端窄屏下笔记卡的操作按钮直接可见
