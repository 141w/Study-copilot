**SQLite 掩盖、PG 暴露的点**（本次实测确认）：
1. PG 开外键——测试数据必须先 commit `users` 再插 `documents`；SQLite 不开外键会静默通过。
2. PG 的 UPDATE/DELETE 严格按行数同步；失败路径 rollback 后再读，语义与 SQLite 一致，但事务边界错误在 PG 上更早以 `ForeignKeyViolation` / 丢行形式暴露。
